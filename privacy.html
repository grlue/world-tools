개인정보처리방침 · Privacy Policy

시행일 2026-10-03 · Effective 2026-10-03

World Clips Uploader는 채널 운영자 본인만 쓰는 비공개 도구이며 YouTube API 서비스를 사용합니다. Google의 개인정보 처리는 Google 개인정보처리방침을 따릅니다.

World Clips Uploader is a private tool used only by the channel operator. It uses YouTube API Services. Google's handling of data is governed by the Google Privacy Policy.

접근하는 정보 · Data accessed

  • 로그인한 계정의 채널 ID와 채널 이름 (업로드 대상 채널 확인용)
  • 운영자가 업로드하는 영상과 그 제목·설명
  • 운영자 채널 영상의 통계: 조회수, 시청 시간, 평균 시청률, 시청 지속 곡선, 좋아요·공유·댓글 수, 구독자 증감

The signed-in account's channel ID and name (to confirm the upload target), the videos and metadata the operator uploads, and statistics for the operator's own videos (views, watch time, average view percentage, retention curve, likes, shares, comment counts, subscriber changes).

이용과 보관 · Use and storage

  • 정보는 다음 영상 제작을 개선하는 데에만 씁니다. 광고·판매·프로파일링에 쓰지 않습니다.
  • 인증 토큰과 통계는 운영자의 컴퓨터에만 저장합니다. 제3자와 공유하거나 외부 서버로 보내지 않습니다.
  • 다른 사용자나 시청자의 개인정보는 수집하지 않습니다.
  • 권한을 철회하면 저장된 통계와 토큰을 삭제합니다.

Data is used only to improve future videos, never for advertising, sale or profiling. Tokens and statistics are stored only on the operator's own computer and are not shared with third parties or sent to external servers. No personal data of other users or viewers is collected. Stored statistics and tokens are deleted when access is revoked.

권한 철회 · Revoking access

Google 계정 보안 설정에서 언제든 이 도구의 접근 권한을 철회할 수 있습니다.

Access can be revoked at any time from the Google security settings page.

변경 · Changes

이 방침이 바뀌면 이 페이지의 시행일을 고칩니다.

If this policy changes, the effective date on this page will be updated.
